# Security scan evidence

These are byte-identical copies of the generated reports, canonical findings and coverage records from three completed Codex Security scans. Their SHA-256 values are in index.json. Each scan used explicitly selected gpt-6.1-sol and completed its discovery/validation/reportability workflow; no reportable findings survived. The baseline is a historical whole-repository scan; the next two scans cover the subsequent portable-identity and workflow deltas. Read each report for its exact commit range, surfaces and limitations.

This chain does not claim a fresh whole-repository scan at the final commit, exhaustive absence of vulnerabilities, independent host attestation or completion of the full matrix/manual gates. Earlier failed attempts and all independent findings/repairs remain separately retained. Report statements about live or pending measurements describe their scan-time observations.
