# Experimental POSIX integration packet, revision 2

The packet exercises three real filesystem cases with synthetic original bytes:
successful publication/restoration and full copied-tree sealing; an exclusive
final-name collision preserving both prior final and new partial; and copied
packed-byte corruption refused by the real resolver/adapter. It does not run
Go, generate benchmark measurements, qualify recall or authorize retirement.
Actual execution of these three POSIX cases remains NOT RUN.

The selected dependency variants have independently reviewed descriptor ownership
repairs. Actual bounded local results are 37 injected fault controls, 77 existing
science units (41 registry, 21 adapter, 15 driver), and four startup/local controls,
all passing with zero skips. Two startup controls run real native Python
subprocesses; fake descriptor numbers never reach an actual kernel close.
Those outcomes do not establish filesystem durability or real kernel faults.

All imports are from an exact flat source packet verified before adding its path
to Python's import path. Start the launcher with `python3 -I -S -B`. Its source
manifest digest and the separate admission document digest are trusted external
inputs. Unknown local modules, pyc files and package trees refuse. The packet's
admission template is deliberately refused and must never be used as a grant.

The integration profile is `scientific-posix-integration-retain-all-v2`, runner
context `explicit-owned-quota-posix-v2`, admission format
`scientific-posix-runner-admission-v2`. Every source original, primitive staging
file, packed candidate, partial/final catalog, registry pair, unknown entry,
failure tail, copied tree and failure envelope remains evidence. Retirement
continues to refuse. No automatic deletion, retry, migration or legacy gzip
reinterpretation is supplied by this packet.

An external lifecycle must establish an actual bounded Linux filesystem, actual
allocation denial, actual child memory enforcement/denial, producer quiescence,
complete failure collection and all-allocation admission before this launcher
runs. A context boolean, manifest hash or monitoring report supplies none of
those kernel facts. The older 35 MB failure selector and historical first
packet/manifest are incompatible with this retained-all profile.

The finite placement and transport arithmetic is in BOUNDS.md. The candidate
uses a 256 MiB disk image and a distinct 512 MiB memory limit. Neither number
changes the source or scientific caps. All external custody copies, temporary
file references and uncertain mirrors require additional accounting. Unsafe or
uncopyable trees remain explicitly incomplete and require a previously admitted
closed raw-image fallback; a successful selected subset is never a complete
failure collection.

Source review and local unit evidence are complete only for their stated scope.
The external lifecycle is a separate source candidate requiring its own first
independent findings. Actual POSIX execution, cloud/native custody, native
scientific collector/analyzer wiring, versioned post-retirement state, complete
5400-cell matrices for each of readers 1/4/16, reference-host qualification and
release gates remain separate NOT RUN or NOT IMPLEMENTED work.
