# Third-party notices and data provenance
The product implementation is original Go code. It uses the Go standard library and no third-party runtime Go module. Python verification scripts use the standard library. Toolchains retain their upstream licenses; their binaries are not redistributed in this source package.

The HNSW research paper informs the algorithmic design; no paper figures or implementation source were copied. See REFERENCES.md. hnswlib is an optional Apache-2.0 comparator, not a product dependency and not bundled. An optional Wine Quality dataset track would require its CC BY 4.0 attribution; it has not been bundled or used for the recorded smoke experiment.

Examples and benchmark workloads are generated synthetic data. They do not contain resume data, employer records or user information. GitHub Actions are pinned to source commits; their own licenses remain applicable. No font files, screenshots from third-party products, model weights or proprietary assets are included.
